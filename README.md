# Estudos de Docker

Este repositório reúne minhas anotações de estudo sobre Docker e containers. Faz parte de uma sequência com os meus outros repositórios de estudo, [estudos-linux](https://github.com/filipoow/estudos-linux) e [estudos-git-github](https://github.com/filipoow/estudos-git-github). A ideia continua a mesma: material simples de ler, mas aprofundado o suficiente para entender de verdade como as coisas funcionam por baixo, não só decorar comandos.

Cada arquivo cobre um tema e traz fontes ao final, para quem quiser ir além.
